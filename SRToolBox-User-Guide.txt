SRToolBox 申瑞工具箱
==================

下载地址
--------

访问Releases页面下载最新版本：
https://github.com/Verherder/SRToolBox-Releases/releases

下载以下文件，下载最新版本：
- SRToolBox.exe - 应用程序
- setup_env.bat - 环境配置脚本
- environment.yml - paddle环境和依赖定义
- PDFtoPrinter.exe - PDF打印程序（必需）
- SRToolBox-User-Guide.txt - 本文件


环境配置
--------

方式一：使用 setup_env.bat 自动配置（推荐）

1. 将下载的所有文件放到同一目录
2. 双击运行 setup_env.bat
3. 脚本会自动：
   - 检查是否已安装 Miniforge/mamba
   - 按 environment.yml 创建或更新 paddle 环境
   - 安装项目需要的 Python 3.10 和全部依赖


方式二：手动配置

1. 安装 Miniforge，并确认命令行可执行 mamba

2. 在上述文件所在目录创建环境
   mamba env create -f environment.yml

3. 已存在 paddle 环境时执行更新
   mamba env update -n paddle -f environment.yml --prune

4. 验证环境
   mamba run -n paddle python --version


运行应用
--------

双击 exe 运行即可。

程序通过 SRTOOLBOX_CONFIG_PATH 使用统一配置文件；客户版启动器默认使用
D:\venv\config.yaml，用于保存打印机、输出目录等设置。

重要：config.yaml 保存了您的个人设置，删除后将无法恢复。
如果误删，请重新下载 exe 并双击运行，程序会自动创建新的配置文件。

常见问题
--------

Q: 运行报错 "DLL load failed"
A: 需要安装 Visual C++ Redistributable
   下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe

Q: 报错 "qpdf##.dll not found" 或类似错误
A: PDFtoPrinter 需要 x86 版本的最新版的 VC Redistributable，
   下载地址：https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
   选择 x86（非 x64）版本安装

Q: pip 安装失败
A: 检查网络连接，或尝试切换其他镜像源

Q: 找不到 Python
A: 确保按setup_env.bat成功创建venv环境
